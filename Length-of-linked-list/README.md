# Length of Linked List

**Difficulty:** Basic

## Problem Statement

Given the **head** of a Singly Linked List, find the **length** of the Linked List, where length is defined as the total number of nodes present in the Linked List.

## Examples

**Example 1:**

**Input:**
```text
LinkedList = 1 -> 2 -> 3 -> 4 -> 5
```

**Output:**
```text
5
```

**Explanation:** The length of the Linked List is 5, as there are 5 nodes present in it.

**Example 2:**

**Input:**
```text
LinkedList = 2 -> 4 -> 6 -> 7 -> 5 -> 1 -> 0
```

**Output:**
```text
7
```

**Explanation:** The length of the Linked List is 7, as there are 7 nodes present in it.

## Constraints

- \(1 \leq \text{size of Linked List} \leq 4 \times 10^4\)
- \(1 \leq \text{Node.data} \leq 10^3\)
