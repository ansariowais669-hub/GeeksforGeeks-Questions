# Add 1 to a Linked List Number

**Difficulty:** Medium

## Problem Statement

You are given the head of a linked list where each node contains a single digit. The digits together represent a number formed by concatenating the node values in order.

Add 1 to this number and return the head of the modified linked list.

## Examples

**Example 1:**
```text
Input:  4 -> 5 -> 6
Output: 4 -> 5 -> 7
```

**Example 2:**
```text
Input:  1 -> 2 -> 3
Output: 1 -> 2 -> 4
```

**Example 3:**
```text
Input:  0 -> 0 -> 1
Output: 0 -> 0 -> 2
```

**Example 4:**
```text
Input:  9 -> 9 -> 9
Output: 1 -> 0 -> 0 -> 0
```

## Constraints

- 1 ≤ size of linked list ≤ 10⁵
- 0 ≤ Node.data ≤ 9
