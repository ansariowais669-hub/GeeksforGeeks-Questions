# Search in Linked List

**Difficulty:** Basic

## Problem Statement

Given the **head** of a Singly Linked List and an integer **key**, check whether the given key is present in the Linked List or not.

Return **true** if the key is found; otherwise, return **false**.

## Examples

**Example 1:**

**Input:**
```text
key = 3
LinkedList = 1 -> 2 -> 3 -> 4 -> 5
```

**Output:**
```text
true
```

**Explanation:** The key 3 is present in the Linked List.

**Example 2:**

**Input:**
```text
key = 4
LinkedList = 1 -> 2 -> 3 -> 5 -> 6
```

**Output:**
```text
false
```

**Explanation:** The key 4 is not present in the Linked List.

## Constraints

- \(1 \leq \text{size of Linked List} \leq 10^5\)
- \(1 \leq \text{key} \leq 10^5\)
