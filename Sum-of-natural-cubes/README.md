# Sum of Natural Number Cubes

**Difficulty:** Basic

## Problem Statement

Given an integer `n`, calculate the sum of the series:

\[
1^3 + 2^3 + 3^3 + 4^3 + \ldots + n^3
\]

Return the sum of the first `n` natural number cubes.

## Examples

**Example 1:**

**Input:**
```text
n = 5
```

**Output:**
```text
225
```

**Explanation:**

\[
1^3 + 2^3 + 3^3 + 4^3 + 5^3 = 225
\]

**Example 2:**

**Input:**
```text
n = 7
```

**Output:**
```text
784
```

**Explanation:**

\[
1^3 + 2^3 + 3^3 + 4^3 + 5^3 + 6^3 + 7^3 = 784
\]

## Constraints

- 1 ≤ n ≤ 200
