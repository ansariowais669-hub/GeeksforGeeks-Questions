# Linked List End Insertion

**Difficulty:** Basic

## Problem Statement

You are given the **head** of a Singly Linked List and an integer **x**. Insert a new node with value **x** at the end of the Linked List and return the **head** of the modified Linked List.

## Examples

**Example 1:**

**Input:**
```text
x = 6
LinkedList = 1 -> 2 -> 3 -> 4 -> 5
```

**Output:**
```text
1 -> 2 -> 3 -> 4 -> 5 -> 6
```

**Explanation:** The new node containing 6 is inserted at the end of the Linked List.

**Example 2:**

**Input:**
```text
x = 1
LinkedList = 4 -> 5
```

**Output:**
```text
4 -> 5 -> 1
```

**Explanation:** The new node containing 1 is inserted at the end of the Linked List.

## Constraints

- \(0 \leq \text{size of Linked List} \leq 10^5\)
- \(0 \leq \text{Node.data}, x \leq 10^5\)
